# Guía 4 - Notas de calidad

Este proyecto se usa como referencia para aplicar conceptos de gestión de calidad del software.

Controles incluidos:
- Autenticación de usuarios.
- Hash de contraseñas.
- Restricción de un voto por usuario y elección.
- Validación de elección/candidato.
- Pruebas automáticas con pytest.
- Base de datos relacional.
- Endpoint de salud `/health`.

Métricas propuestas:
- Disponibilidad >= 99,5 % durante una elección.
- P95 de respuesta <= 2 s.
- Vulnerabilidades críticas = 0.
- Registros/votos inconsistentes = 0.
- Cobertura objetivo de pruebas >= 80 %.
